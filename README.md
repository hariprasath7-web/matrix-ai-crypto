# MATRIX AI CRYPTO — Ultra Dashboard

A Streamlit educational prototype with a dark navy / purple / cyan dashboard, custom inline shield logo, Hill Cipher encryption and decryption, and rule-based session monitoring.

## Run locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run Matrix_AI_Crypto.py
```

## Deploy
Upload `Matrix_AI_Crypto.py`, `requirements.txt`, and `.streamlit/config.toml` to the root of a GitHub repository. In Streamlit Community Cloud choose branch `main` and main file `Matrix_AI_Crypto.py`.

## Important
This uses a classical Hill Cipher and simple rule-based monitoring. It is a classroom demo, not production security and not a trained AI model.
